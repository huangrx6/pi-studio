我的 Mac 该下载哪个安装包？

Apple 芯片选择 arm64.dmg，Intel 芯片选择 x64.dmg。打开磁盘映像，将应用拖入「应用程序」。查看首次安装说明 ↗

开始对话前，需要准备什么？

在「设置 → 模型配置」里添加服务地址和凭据，启用一个模型。新建对话，选择项目文件夹与工具权限后即可开始。

项目、会话和凭据存在哪里？

文件保存在你选择的工作区，Studio 在本机管理会话与设置。凭据由系统加密保存。使用远程模型时，请求会发送到配置的提供方。了解数据与权限 ↗
