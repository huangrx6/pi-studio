# Pi Studio v0.0.13

这一版是一次整体视觉规范的重做：窗口变成壁纸上的不透明卡片，界面只保留四级表面、一套选中态和一条顶部标题行；同时把模型对比工作台搬进右侧面板。

## 窗口与表面

- 自定义背景改为「壁纸在窗口外」：壁纸铺满整个视口，应用窗口是四周留白 12px、顶部 36px 的不透明卡片，圆角 12px 并带投影。
- 窗口内所有表面都是不透明四级色（画布 / chrome / raised / floating），不再有玻璃与半透明叠加；纯红、纯蓝、暗色照片三张壁纸下，侧栏、画布、标题栏与输入框取色差为 0。
- 「界面遮挡」改名为「遮罩强度」，真正压在壁纸层上（默认 30%），只影响窗口外的壁纸，不影响窗口内表面。
- 品牌与应用名并入窗口控制行，与 macOS 红黄绿同一行；有壁纸或全屏时自动左移到 16px，空状态不再保留第二层占位标签行。

## 排版与组件

- 正文 15px / 1.75，阅读列收到 740px，段距保持 12px。
- 行内代码改为 6% 文字色 tint、13px 等宽；代码块换成 raised 表面 + 边框，顶部 chrome 条显示语言并提供复制。
- 文件变更块去掉卡片底色与字母标记，改用弱分割线、等宽路径与「新增 / 修改 / 删除 / 写入」文字标签。
- 计划栏并入输入框上方一行 32px，底部压一条 2px 进度线；底部状态行去掉底色，改 12px 弱文字。
- 选中态收敛成一套：tint 底 + text-1 文字 + accent 图标，标签用底部 2px 下划线，不再额外加左侧竖条。
- 「新会话」改为次级按钮（raised + 1px 边框 + accent 加号）；发送按钮在有内容时实心强调、空输入时退回 hover 表面。

## 空状态与输入框

- 新会话欢迎区重做：一条短 accent 线、一句衬线标题「今天想做点什么？」和一行说明，任务示例退成无边框胶囊。
- 去掉「选择工作区 / 配置模型」两个按钮：工作区选择器常驻输入框，模型胶囊常驻；未配置模型时点击输入框会弹出配置提示，带直接的「配置模型」入口。

## 工作台与轨迹

- 模型对比工作台搬进右侧面板，成为与文件、终端并列的 tab，切换面板不会丢掉正在跑的对比。
- 轨迹详情抽成共享条目模型，菜单与详情面板使用同一份数据。

## 其它

- 用量页热力图按可用宽度自适应，365 天不再横向滚动；模型筛选改为统一的选择器。
- 轨迹页由「显示代码工作视图」偏好控制，关闭时回落对话。
- 第二个实例启动时会明确提示「另一个 Pi Studio 正在使用这份应用数据」，不再静默退出。

## 验证

- Node 契约、状态机、Durable 与主题测试 1194 项全部通过，TypeScript 检查与生产构建通过。
- 新增 `tools/qa/qa-shell-acceptance.mjs`：三壁纸取色漂移 0、不透明表面不超过四级、text-1 对比度 18.58、text-2 对比度 5.80。
- UI QA 实跑通过：设置页 13 个路由、窗口全屏与窗口尺寸、背景设置、文件变更摘要、用量与模型筛选。
- 亮色 / 深色、有壁纸 / 无壁纸、窗口 / 全屏四种组合均截图核对。

## 安装与升级

- Apple Silicon：`Pi-Studio-0.0.13-arm64.dmg`
- Intel：`Pi-Studio-0.0.13-x64.dmg`
- 自动更新：对应架构的 `.zip`、`latest-mac.yml` 与 blockmap 文件。
- 系统要求：macOS 13+

本版本继续使用固定自签名身份，尚未经过 Apple Developer ID 签名与公证。首次打开时，请在「系统设置 → 隐私与安全性」中允许；也可以仅在确认安装包来自本项目 Release 后执行：

```bash
xattr -cr "/Applications/Pi Studio.app"
```
