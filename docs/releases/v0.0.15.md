# Pi Studio v0.0.15

这一版把计划栏和文件变更块重新收了一遍，修掉用户消息气泡的三个排版问题，并明确了扩展 chip 的作用域。

## 会话排版

- 已发送消息的附件条改为与气泡同一条右边缘：一张时贴右，内容变多时自己长宽，只有超过 `min(85%, 560px)` 才开始横向滚动。
- 修掉短句被拆成两行的问题：「请查看图片。」这类消息之前因为外层 `align-items: flex-end` 让容器收缩到 fit-content，气泡的 `max-width: 85%` 按被压窄的宽度计算。现在 `.user-message` 撑满整行、内层右对齐，气泡按 `max-content` 取宽。
- 用户消息的换行从 `overflow-wrap: anywhere` 收到 `break-word`：中文短句不再被随便拆开，长串（URL、路径）仍会在必要时断行。

## 计划栏

- 折叠态从「标题 + 贯穿整宽的 2px 进度线」改成 28px 的状态胶囊：图标 + 「计划」+ 当前任务 + 44×3 迷你进度 + 计数，悬停才出现一层 hover 底。
- 全部完成时连迷你进度一起收掉，只留「全部完成 9/9」，不再是那条常亮的满格灰线。
- 展开后的任务列表仍是带边框卡片，与胶囊间隔 6px。

## 文件变更

- 重新装回明确的框：1px 边框 + 圆角 + raised 底色，头部与文件行之间一条弱分割线；图标换成 24px 圆角小方块。
- 保留上一版的改进：文件名等宽、状态是「新增 / 修改 / 写入」文字标签、行数右对齐、可点行带 chevron。

## 扩展

- `status.chip` 明确为会话级入口：新会话是草稿态，没有 `sessionId`，扩展的数据源与 `details` 面板都无从指认，因此一律不渲染 chip。判定写成纯函数 `scopedExtensionChips`，由宿主统一裁剪。
- 文档补齐三种入口的分工：`status.chip` = 会话内入口，`conversation.footer` = 输入框附近一行状态，`status.bar` = 不分页面的常驻状态。

## 验证

- Node 契约、状态机、Durable 与主题测试 1195 项全部通过，TypeScript 检查与生产构建通过。
- 扩展 schema 生成、示例扩展校验、`qa-docs` 通过。
- UI QA 实跑通过：会话审查（含横向图片画廊与 diff review）、文件变更摘要、背景与窗口、设置页 13 个路由、三壁纸取色验收。
- 用户消息气泡的宽度与行数用真实 `ChatMessageView` 逐条量过：短句 118px 单行、长句 426px 单行、含附件的短句 118px 单行且与附件卡右边缘对齐。

## 安装与升级

- Apple Silicon：`Pi-Studio-0.0.15-arm64.dmg`
- Intel：`Pi-Studio-0.0.15-x64.dmg`
- 自动更新：对应架构的 `.zip`、`latest-mac.yml` 与 blockmap 文件。
- 系统要求：macOS 13+

本版本继续使用固定自签名身份，尚未经过 Apple Developer ID 签名与公证。首次打开时，请在「系统设置 → 隐私与安全性」中允许；也可以仅在确认安装包来自本项目 Release 后执行：

```bash
xattr -cr "/Applications/Pi Studio.app"
```
