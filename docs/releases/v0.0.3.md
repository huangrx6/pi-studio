# Pi Studio v0.0.3

本次版本集中完善了桌面体验、模型与运行时配置、长会话性能和应用更新流程。

## 新增

- 六套全局配色与统一语义颜色系统。
- 图片、GIF、视频背景及透明度 / 模糊控制。
- 不落盘的临时聊天，支持文字、图片、流式回复和停止。
- GitHub Release 检查更新、下载进度与安装时机选择。
- 菜单栏运行会话、完成提醒与待查看更新。
- 模型来源、模型发现、能力元数据和全局默认模型管理。
- thinking 分层配置、会话级覆盖与运行时热加载。
- 子 Agent 总览、上下文查看、角色模型与工具权限配置。
- 可调宽 Git 差异工作台与标签页操作。

## 修复

- 修复长流式输出时底部运行状态和绿色轨道抖动。
- 修复流式输出停止贴底、上滚卡顿和发送后延迟滚动。
- 修复新会话记录不同步、切换“新对话”后丢失当前会话。
- 修复模型显示回退、历史模型丢失和运行中无法预选下一轮模型。
- 修复长粘贴拆分错位、图片压缩状态和附件预览问题。
- 修复 Agent 工具配置必须重启应用才能生效。

## 优化

- 流式更新按帧合并，活跃回合保持稳定布局，已完成回合按视口渲染。
- 长会话分页、完整大纲跨页跳转与顶部自动补载。
- 空闲 Agent 运行时释放，会话详情、文件、子 Agent 和工具目录缓存均设上限。

## 验证

- 130/130 单元测试通过。
- TypeScript 与 Vite 生产构建通过。
- 主题、完整 UI、背景、更新、临时聊天、长会话、流式轨迹和滚动跟随浏览器回归通过。

## 安装

- Apple Silicon：`Pi-Studio-0.0.3-arm64.dmg`
- Intel：`Pi-Studio-0.0.3-x64.dmg`
- 系统要求：macOS 13+
