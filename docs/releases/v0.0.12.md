# Pi Studio v0.0.12

这个版本重做了会话执行轨迹页，并统一了深色主题的表面层级与自定义背景下的可读性。设置中心的单色令牌、56px 行节奏、步进器与即时保存确认沿用 v0.0.11。

## 执行轨迹

- 轨迹页新增筛选：全部 / 模型 / 决策 / 工具，以及按标签、摘要和原始内容进行的全文搜索；没有匹配时给出明确的空状态。
- 每一步改为可点开的行：左侧序号、类型图标、类型标签与时间，下面是动作标题和摘要，右侧是状态与进入箭头。
- 详情用统一弹层承载：状态、时间、步骤 ID、摘要与完整执行内容分区展示，长内容在弹层内滚动，不再挤压列表。
- 对话里的“工作过程”只保留本轮真实执行的动作；模型请求统一收进轨迹页，避免同一次请求在对话和轨迹里各出现一遍。
- 非流式回答会把整轮过程收敛为一段，折叠后立即释放已展开的工具内容，长会话的 DOM 更轻。
- 工具参数区改为无描边的浅表面，展开内容与行内标题对齐，不再贴着图标边线。

## 主题与背景

- 深色主题重建三级表面层级（页面 / 卡片 / 控件），主内容、卡片与输入区不再糊成一块黑。
- 热力图低、中档色阶与纯黑页面底拉开明度差，低使用量和中等使用量不再整块消失。
- 自定义背景下的设置页改用一层可读的深色玻璃：背景持续可见，内容保持对比，滚动时不再出现遮挡层断开。
- 背景媒体块收敛为一条摘要行（文件名 + 类型 + 折叠箭头），展开后左预览、右滑杆同顶同底，首个滑杆标签与预览图上沿齐平。

## 会话与输入

- 会话提交仍在进行时禁用消息编辑，与主进程守卫一致，失败时不再静默。
- 编辑后的消息继续沿用“截断到该条并重新请求”的语义：后续消息被忽略，新的回答重新生成。

## 安装与升级

- Apple Silicon：`Pi-Studio-0.0.12-arm64.dmg`
- Intel：`Pi-Studio-0.0.12-x64.dmg`
- 自动更新：对应架构的 `.zip`、`latest-mac.yml` 与 blockmap 文件。
- 系统要求：macOS 13+

本版本继续使用固定自签名身份，尚未经过 Apple Developer ID 签名与公证。首次打开时，请在“系统设置 → 隐私与安全性”中允许；也可以仅在确认安装包来自本项目 Release 后执行：

```bash
xattr -cr "/Applications/Pi Studio.app"
```
