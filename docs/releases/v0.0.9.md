# Pi Studio v0.0.9

这个版本同步 Pi Durable 1.5，并集中完善资源、凭据、子智能体、模型对比和共享页面交互。Durable 继续负责执行事实，Studio SQLite 只保存投影、设置、资源信任和受管元数据。

## Durable 1.5

- Pi Studio 的 Durable、AI、Chord、MCP 与 Telemetry 依赖整体升级到 1.5.0，不混用旧版本。
- 实时会话改用 `ConversationView` 投影，任务状态改用 `watchTaskGraph()`，并适配新的失败、任务和流式事件契约。
- 工具定义统一由 Studio 自己的 JSON Schema 构造器生成，保留现有开放对象行为，并增加 API 面、投影和 Schema 护栏。
- 新增升级检查工具与迁移记录，明确数据库快照、文档版本和无法直接降级的边界。

## 工作区与资源

- 新增 Skill Hub，支持本地目录与静态 registry JSON 来源、完整描述预览、完整性校验、隔离安装、更新和卸载。
- 新增加密凭据库、敏感输入检查和 `{{secret:NAME}}` 工具占位符；明文只在主进程执行边界短暂展开，并统一脱敏工具输出与诊断。
- HTTP MCP 支持显式 OAuth 登录、PKCE、加密状态持久化和退出登录；MCP 设置提供连接测试与工具检查。
- 子智能体新增并发、预算、独立用量、监督回复和 Git 工作树生命周期；工作树创建、采用、保留与回收都经过串行化和失败保护。
- 新增模型双跑对比：从当前会话分叉两个隔离工作树，分别执行、查看结果与用量，再选择采用一个分支或丢弃。

## 会话与界面

- 输入框与 `Cmd/Ctrl+K` 共用可搜索的动作面板；列表/详情页面采用统一响应式结构。
- 新增上下文占用、会话大纲同步、用量筛选、请求总数与子智能体状态展示。
- 设置页、Skill Hub、凭据库、模型对比、MCP 与子智能体页面统一标题、间距、字体、空态、错误态和危险操作层级。
- 对话框统一焦点进入、焦点循环、Escape 关闭与焦点恢复；深浅色和紧凑窗口保持一致的控件尺寸与可读性。

## 可靠性与回归

- Skill 安装使用预览绑定的目标、完整文件图、SHA-256 和原子切换，迟到刷新不会恢复已删除来源。
- 模型对比、工作树清理、子智能体等待和累计用量修复了跨边界身份、并发与重试问题。
- `pnpm test`：506/506 通过。
- TypeScript 检查、Vite 生产构建、扩展 Schema、示例扩展校验和浏览器交互 QA 通过。
- 浏览器 QA 覆盖深浅色、窄窗口、键盘焦点、空态、错误态与剪贴板流程。

## 安装与升级

- Apple Silicon：`Pi-Studio-0.0.9-arm64.dmg`
- Intel：`Pi-Studio-0.0.9-x64.dmg`
- 自动更新：对应架构的 `.zip`、`latest-mac.yml` 与 blockmap 文件。
- 系统要求：macOS 13+

v0.0.9 会执行 Studio SQLite v17 迁移，并使用 Pi Durable 1.5 的文档格式。若需要保留直接回退到 v0.0.8 的能力，请在首次启动新版本前先退出应用并备份 `pi-studio.sqlite`；开始写入 1.5 文档后，单纯降级应用不够。

本版本继续使用固定自签名身份，尚未经过 Apple Developer ID 签名与公证。首次打开时，请在“系统设置 → 隐私与安全性”中允许；也可以仅在确认安装包来自本项目 Release 后执行：

```bash
xattr -cr "/Applications/Pi Studio.app"
```
