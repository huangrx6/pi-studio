# Pi Studio 版本记录

v0.0.1 至 v0.0.5 按五个产品阶段整合了早期版本，后续版本按发布顺序编号。

| 版本 | 原版本范围 | 主要变化 |
| --- | --- | --- |
| [v0.0.11](../../.github/release-notes/v0.0.11.md) | — | 额度认证扩展、设置页面隔离和统一折叠组件 |
| [v0.0.10](../../.github/release-notes/v0.0.10.md) | — | 视频分镜、旁白试听、成片导出和输入框样式 |
| [v0.0.9](../../.github/release-notes/v0.0.9.md) | — | 多仓库工作区、文件预览、并行子智能体和会话内容展示 |
| [v0.0.8](../../.github/release-notes/v0.0.8.md) | — | Git 远端管理与同步预览、按项目查看用量、模型额度预览 |
| [v0.0.7](../../.github/release-notes/v0.0.7.md) | — | 会话进展与任务历史、子智能体头像、扩展图标与配色、Git 提交与同步、工作树管理 |
| [v0.0.6](../../.github/release-notes/v0.0.6.md) | — | Windows 标题栏、系统托盘、快捷键与文件路径，会话视图导航，按模型来源显示额度 |
| [v0.0.5](../../.github/release-notes/v0.0.5.md) | v0.0.23–v0.0.28 和本轮改动 | 会话工作台、提问导航、模型额度监控、Pi Durable 1.5.2 |
| [v0.0.4](../../.github/release-notes/v0.0.4.md) | v0.0.19–v0.0.22 | 长对话、终端和独立数据目录 |
| [v0.0.3](../../.github/release-notes/v0.0.3.md) | v0.0.11–v0.0.18 | 设置中心、执行轨迹、模型对比与外观 |
| [v0.0.2](../../.github/release-notes/v0.0.2.md) | v0.0.4–v0.0.10 | Pi Durable、独立存储、长期任务与子智能体协作 |
| [v0.0.1](../../.github/release-notes/v0.0.1.md) | v0.0.1–v0.0.3 | 桌面对话、工作区和变更审阅 |

从 v0.0.6 起，提供 Windows x64、Apple 芯片 Mac 和 Intel Mac 安装包。原 v0.0.6 至 v0.0.28 用户请按最新版发布说明手动换装。[下载最新版](https://github.com/huangrx6/pi-studio/releases/latest)
