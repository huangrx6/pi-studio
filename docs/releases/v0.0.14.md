# Pi Studio v0.0.14

这一版把输入区整体压扁、让壁纸真正透进窗口，并把「顶栏状态入口」做成扩展契约（`status.chip`），同时退役了语义重叠的 `conversation.header`。

## 背景与窗口

- 新增「窗口内可见度」（设置 → 外观 → 背景，默认 8%）：卡片内部铺一层同源壁纸，侧栏、标题行、标签行与画布按同一比例透出，整窗是同一个透度，不再是「画布透、侧栏实」。
- 消息气泡、输入框、菜单、对话框仍然不透明，阅读底不受影响；滑到 0 就是之前的纯净版。
- 卡片留白改为顶部 44px、左右与底部 18px，红绿灯不再贴着卡片边。
- 「界面遮挡」改名「遮罩强度」后只压暗窗口外的壁纸，与窗口内可见度各管一段。

## 输入区

- 空输入框从 200px 收到 96px：单行正文 + 紧凑工具条，输入变长后自动长高（最多 8 行）。
- 框内附件缩成 40px 方块，一张截图不再撑高半屏；圆角收到 12，焦点从 3px 实心环改成 1px 边框加一层 tint 光晕。
- 未配置模型时，点击输入框会弹出配置提示，带直接的「配置模型」入口。
- 已发送消息的附件移到气泡上方，合成一行（最宽 `min(85%, 560px)`）横向滚动：图片 96×72 缩略、文件卡 40px 单行。

## 计划与排队

- 计划栏全部完成时自动收起为一行摘要，进度线退成弱色；用户手动展开后不再自动收起，直到出现新的未完成任务。
- 排队消息行高 38 → 32，插话 / 编辑 / 删除改为悬停显形；超过两条先折叠成「展开全部 N」。
- 空状态只留一条短线与一句「今天想做点什么？」，说明文字与示例胶囊一并移除。

## 设置

- 滑杆获得焦点时不再给整行画一个直角白框，焦点提示收回到滑块光环与轨道描边。

## 扩展契约

- 新增 `status.chip` slot：扩展在顶栏声明一个图标入口（最多三个，按 `priority` 排序），悬停或键盘聚焦展开同一份紧凑摘要，点击打开 `details` 指向的 `conversation.detail` 面板。`details` 必须指向同一份 manifest 里的详情面板，写错会在校验时报错。
- `conversation.footer` 与 `status.chip` 支持 `visibility: while-active`：只在回合进行中渲染，空闲时不占高度。Studio 指标扩展已改用这个语义——底部那行摘要只在生成中出现。
- 移除 `conversation.header`：它渲染成标题行下方的一条 dock，语义与 `status.chip` 重叠且没有扩展在用；声明它的扩展现在会在 manifest 校验时报「未知 slot」。
- 文档与 schema 同步更新，slot 表现在是：`workspace.sidebar`、`conversation.detail`、`conversation.footer`、`status.chip`、`status.bar`、`composer.before`、`settings.panel`、`panel.side`。

## 验证

- Node 契约、状态机、Durable 与主题测试 1194 项全部通过，TypeScript 检查与生产构建通过。
- 扩展 schema 生成、示例扩展校验通过；`qa-docs` 通过。
- UI QA 实跑通过：背景与窗口、设置页 13 个路由、会话审查、三壁纸取色验收（可见度 0 时漂移仍为 0）。
- 亮色 / 深色、有壁纸 / 无壁纸、窗口 / 全屏均截图核对。

## 安装与升级

- Apple Silicon：`Pi-Studio-0.0.14-arm64.dmg`
- Intel：`Pi-Studio-0.0.14-x64.dmg`
- 自动更新：对应架构的 `.zip`、`latest-mac.yml` 与 blockmap 文件。
- 系统要求：macOS 13+

本版本继续使用固定自签名身份，尚未经过 Apple Developer ID 签名与公证。首次打开时，请在「系统设置 → 隐私与安全性」中允许；也可以仅在确认安装包来自本项目 Release 后执行：

```bash
xattr -cr "/Applications/Pi Studio.app"
```
