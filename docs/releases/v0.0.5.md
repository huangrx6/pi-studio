# Pi Studio v0.0.5

这是一个修复会话生命周期、长期任务计划与 macOS 更新安装的补丁版本。普通对话现在会等待其完整 Durable 任务树结束，再显示“已完成”和本轮文件变更。

## 修复

- 修复主模型请求结束时，仍在前台或后台运行的子智能体被错误忽略的问题。
- 修复后台任务未结束时提前显示“已完成”和文件变更汇总的问题。
- 修复主请求暂时结束后停止按钮消失的问题。
- 停止会话时同时中止关联的前台与后台子智能体任务。
- 会话快照、侧边栏、消息头和菜单栏完成提醒统一使用完整任务树状态。
- 重新打开应用或切换会话后，从 Durable 任务投影恢复准确运行状态。
- 修复自定义背景下展开工具卡缺少圆角、参数内容贴边和半透明表面不统一的问题。
- 新增内置 `todo` 工具，多步骤工作会在输入框上方创建可恢复、可分叉的会话任务计划。
- 工具结果、用户消息和临时聊天中的图片统一使用固定尺寸横向画廊，支持完整预览和键盘切换。
- 排队消息按会话隔离，切换会话后仍会跟随原会话状态继续发送。
- 新增 Durable 模型请求轨迹，保存每次实际发送的提示词、消息、参数和工具定义；凭据与敏感字段会脱敏，并可在执行轨迹中直接检查。
- 执行轨迹按请求、思考、工具和响应重新分层，图标、标题、摘要、状态与展开按钮统一对齐。
- 输入框草稿按会话独立保存，切换会话或重启应用后，未发送文本和附件仍保留在原会话。
- 编辑排队消息后使用 `Ctrl/Cmd + Enter` 发送，会恢复该消息原有的队列位置。
- 修复点击运行中的会话后，鼠标移开时侧边栏运行指示器不恢复的问题。
- 修复临时会话首次初始化覆盖用户模型选择、模型菜单被裁切和切换模型后继承错误思考等级的问题。
- 普通对话、长期任务和临时会话按当前模型限制图片上传；不支持图片时直接显示在输入框上方，不再依赖通知面板提醒。
- 修复输入图片移除按钮溢出、工具执行状态与右侧标签未垂直居中的界面问题。

## macOS 更新

- 使用固定的 `Pi Studio Self Signed` 证书完整签署应用和自动更新 ZIP。
- Release 流水线在发布前解压 ZIP 并验证签名，签名无效时直接阻止发布。
- 自签名证书保证后续 Pi Studio 版本具有相同更新身份，但不是 Apple Developer ID，也没有公证。
- 由于历史版本缺少有效整包签名，首次迁移到重新发布的 v0.0.5 需要手动安装 DMG；后续版本可使用应用内更新。

## 验证

- 358/358 单元、契约与集成测试通过。
- TypeScript 与 Vite 生产构建通过。
- UI 回归覆盖临时会话模型切换与纯文本模型图片拦截、聚合运行状态、文件变更延迟展示、状态恢复、停止操作、会话草稿、排队编辑、模型请求轨迹、侧边栏运行状态与自定义背景下的展开工具卡。

## 安装

- Apple Silicon：`Pi-Studio-0.0.5-arm64.dmg`
- Intel：`Pi-Studio-0.0.5-x64.dmg`
- 系统要求：macOS 13+
