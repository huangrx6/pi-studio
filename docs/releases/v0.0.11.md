# Pi Studio v0.0.11

这个版本完成设置中心、核心工作台和异步状态边界的一轮整体优化：设置面改用单色令牌系统与统一的字号节奏，设置即时生效后有确认反馈，窗口位置会被记住，会话重开后附件信息与体积完整显示。应用继续由 Pi Durable 负责会话、任务与子智能体执行；Studio 只保存自己的 SQLite 投影、设置、资源信任和受管目录。

## 设置中心

- 13 个页面共用页头、外框、间距与字号层级；分组导航、搜索、按需加载和离页草稿保护保持不变。
- 设置面切换到单色令牌：页面、卡片、分割线、控件与悬停各一层黑白灰关系，状态只用 ● ○ △ 与文字表达，不依赖红绿。
- 字号收敛为 24 / 20 / 15 / 14 / 13 / 12（统计值 28），标题 -0.02em，说明 13px/1.6，数字等宽，设置行固定 56px。
- 导航选中态使用选中底色与 1px 内描边；切页 140ms 淡入，开启“减少动态效果”时只淡入。
- 数字项使用步进器：长按连发、点击输入、↑↓ 步进、边界禁用；对话字号范围 12–18px。“工作步骤展示”改为分段控件。
- 即时设置保存后显示“✓ 已保存”，1.2s 淡出；破坏性操作只在悬停或聚焦时显形，并保留二次确认。
- 弹窗统一标题、说明、底部操作栏分割线与 △ 错误样式；焦点环统一 1px 细环；⌘, 打开设置，Esc 退出设置。
- 快捷键页键帽逐键渲染并改用系统字体，修复 ⌘ ⇧ ⌥ 字号不一致与右边缘贴边；使用量页新增近 30 天趋势线与更新时间；宽屏右侧目录下线后，840px 内容列在设置区居中。
- 打开设置不抢焦点，Tab 从标题进入搜索；焦点统一为 1px 细环（导航内描边、输入与下拉共用光晕），Esc 清空筛选后再退出，重开设置不残留焦点环。
- 使用自定义背景时，输入框、多行文本、下拉、步进器与分段控件统一到同一块玻璃表面，不再出现只有下拉是实心黑底的情况。
- 设置页遮挡层跟随内容整段覆盖，滚动后不再出现发白与透出照片的硬接缝；背景块收成摘要行 + 左右两列对齐的预览与滑杆。
- 快捷键卡片内边距四边统一；会话提交未结束时禁用消息编辑，避免编辑后静默失败。
- 通用页分组节奏统一（32px 区块距、12px 标题距），设置行最小 60px；侧栏与页面标题共用一条基线，13 个页面在窄窗、紧凑与宽窗下逐页断言对齐。

## 窗口与附件

- 主窗口记住位置、大小与最大化状态，恢复前按工作区校验，失效时回落到主屏居中；写入 400ms 去抖并在关闭前落盘，菜单提供“重置窗口位置”。
- 原生全屏把标题行统一到 48px 并回收 92px 顶部安全区。
- 长消息附件改名为 `long-message-<YYYYMMDD>-<HHMM>.txt`，展示时去掉存储用 UUID 前缀。
- 重开会话时从附件标记恢复文件名、体积、行数与类型；标记缺失时按受管目录内的实际文件补体积。附件卡片宽度上限 460px，超长名称省略并保留悬停全名。

## 会话、资源与恢复

- Composer、建议菜单、排队消息和附件准备流程保留草稿并覆盖输入法、粘贴、键盘与重复提交边界；长任务、执行轨迹、请求详情与上下文用量继续使用完整历史事实。
- 模型、Provider、MCP、技能、扩展和权限操作使用明确作用域、同步写锁与提交后只读恢复；扩展安装、启用、信任、卸载和回滚具备可恢复事务与真实 SQLite 回滚覆盖。
- 终端补入尺寸屏障、快照与增量输出回放、序列缺口检测和登录 shell 环境加载。

## 安装与升级

- Apple Silicon：`Pi-Studio-0.0.11-arm64.dmg`
- Intel：`Pi-Studio-0.0.11-x64.dmg`
- 自动更新：对应架构的 `.zip`、`latest-mac.yml` 与 blockmap 文件。
- 系统要求：macOS 13+

本版本继续使用固定自签名身份，尚未经过 Apple Developer ID 签名与公证。首次打开时，请在“系统设置 → 隐私与安全性”中允许；也可以仅在确认安装包来自本项目 Release 后执行：

```bash
xattr -cr "/Applications/Pi Studio.app"
```
