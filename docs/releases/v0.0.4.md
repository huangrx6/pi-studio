# Pi Studio v0.0.4

这是 Pi Studio 正式迁移到 **Pi Durable 1.4** 的大版本。普通对话、长期任务、子智能体、流式事件、分叉与恢复统一由 Durable Runtime 执行；Studio 独立管理 SQLite、模型、凭据、Harness、MCP、Skill、权限与扩展。

> **升级说明**
>
> `v0.0.4` 不再读取或回写 Pi CLI 的 `~/.pi`。`v0.0.3` 基于 Pi Coding Agent SDK 的旧会话与配置不会自动映射到新的 Studio SQLite。升级前请保留旧版应用和 userData 备份；升级后需在 Studio 设置中重新配置模型来源、API Key、MCP、Skill 与扩展。

## 新增

- Pi Durable 1.4 成为唯一共享执行引擎，覆盖普通对话、长期任务、子智能体、流式事件、取消、分叉与恢复。
- Studio 自有 `pi-studio.sqlite`，保存会话投影、工作区、模型、凭据、MCP、设置、归档、统计与 `durable_*` 数据。
- 临时聊天使用独立 `MemoryStorage`，不写会话、附件或工作区历史。
- 长期任务入口、状态、归档、恢复和统一时间线。
- 首问异步生成会话标题，不阻塞第一轮回答。
- 子智能体独立上下文、模型、thinking 和工具权限；支持前台、后台并行、supervisor 通信、停止与删除。
- 子智能体总览、运行状态、耗时、只读 transcript、独立页面与返回主 Agent。
- 可配置 Harness profile、八个 Prompt section、应用 / 用户 / 项目级 `AGENTS.md` 和工具 guidance。
- 请求批准、帮我批准、完全权限三种工具策略，以及命令、路径、工具、工作区和会话级覆盖。
- 完全权限直接执行跨工作区操作、动态脚本和普通命令，仅危险删除、系统破坏命令与显式拒绝规则继续拦截。
- 统一渲染层 UUID 与 Durable 数字会话 ID，确保会话级完全权限在运行时稳定命中。
- MCP stdio / Streamable HTTP、延迟工具发现、配置热刷新和活动调用安全退役。
- Skill 按需加载、项目信任指纹、显式 `/skill:<name>` 调用和跨客户端 `.agents/skills` 互操作。
- 模型来源、发现接口、模型能力、thinking 映射、默认模型和 Studio 自有加密凭据。
- Agent 与声明式 UI 扩展、本地 / ZIP / HTTPS / GitHub / registry 安装、签名、升级、回滚和卸载。
- `pi-quota-status` 官方额度扩展与实时 TTFT / 速率指标扩展。
- 按日期和模型聚合的 Token 热力图、连续使用与模型筛选。
- 通知中心、菜单栏运行会话、完成提示音和更新入口。
- 完整 28 章手册、当前版本 2× 高清截图和开发者文档中心。

## 修复

- 修复流式输出状态栏与轨道抖动。
- 修复停止贴底、上滚卡顿、发送后延迟滚动。
- 修复子智能体跨主会话复用、旧状态重开终态和后台任务不结束。
- 修复数据库关闭后设置 / 模型 / 会话操作失败。
- 修复来源发现鉴权、模型能力、额度适配器和自定义模型重复勾选。
- 修复标题不更新、UUID 迁移、归档显示与删除后的关联数据残留。
- 修复完全权限仍反复确认跨工作区命令，以及设置主页按 Escape 会直接退出的问题。

## 优化

- 流式更新按帧合并，长历史与子智能体 transcript 使用窗口和分页。
- 空闲运行时、扩展订阅、文件预览、工具目录和子智能体缓存均设置释放边界。
- SQLite 使用 WAL、`busy_timeout` 和恢复处理。
- 主题、背景、设置页、卡片、按钮、选择框与状态 badge 统一设计令牌。

- TypeScript 与 Vite 生产构建通过。
- 文档、主题、完整 UI、扩展、模型、Harness、权限、子智能体与使用量 QA 通过。
