# Pi Studio v0.0.6

这是一个围绕文件安全、长期任务控制、配置热加载和桌面运行可靠性的版本。Pi Durable 继续作为唯一执行引擎，Studio 保持自己的 SQLite、受管资源和扩展边界。

## 文件与安全

- 附件预览只允许读取 Studio 自己的附件目录，并拒绝目录、缺失文件和符号链接逃逸。
- Git Diff 的绝对路径预览只允许读取当前会话已记录的变更文件。
- 文件操作统一区分工作区、附件和 Diff 来源，主进程 IPC 拒绝来自非主窗口的调用。
- 生产 renderer 增加 Content Security Policy、导航限制、子窗口隔离和 webview 禁用。
- Markdown 图片只接受安全的 HTTP、HTTPS、受支持的内联图片及 Studio 媒体协议。
- 输入框、会话画廊和全屏预览支持右键复制图片；复制前在主进程再次校验 MIME、编码和大小。

## 长期任务与智能体

- 长期任务增加可配置的单次轮次和连续无进展安全阀，达到阈值时保存暂停原因并等待用户确认。
- 后台子智能体停止、取消传播、归属清理和终态恢复保持一致，不会在停止后继续重开。
- Harness、工具、Skill、MCP、子智能体配置和扩展资源继续在下一请求安全边界热加载。
- 工具白名单、权限策略和 Harness profile 保持明确的 scope 与热读取行为。

## 桌面与界面

- 修复应用退出时 Electron 进程可能残留的问题；会话、临时聊天和 Durable Runtime 使用有界关闭。
- 更新安装由 electron-updater 接管退出流程，避免普通清理与新版本安装互相阻塞。
- 统一设置资源卡片、状态 badge、操作按钮、选择框和主题色对比度。
- 修复扩展详情与删除确认层级、模型来源空状态、子智能体配置布局和会话扩展排序。
- 输入框图片、工具结果图片和临时聊天图片使用一致的横向画廊与完整预览。

## 性能

- 流式输出按帧合并，活跃回合保持固定 footer 和左侧状态轨道。
- 历史消息和子智能体 transcript 使用分页窗口，完成步骤支持折叠。
- 模型、文件、扩展订阅、工具目录和子智能体数据分别设置缓存与释放边界。
- 真实 Electron 压力测试覆盖长会话、图片、8 个子智能体、反复切换和完整退出。

## 验证

- `pnpm test`：368/368 通过。
- TypeScript 检查、Vite 生产构建、扩展 Schema 与官方扩展清单校验通过。
- UI、文档、主题、背景、菜单栏、流式稳定性、聊天滚动、图片复制、临时会话、排队消息、请求轨迹、Diff、草稿和更新界面 QA 通过。
- 内存压力峰值约 633 MiB，关闭压力窗口后约 378 MiB，最终 Electron 进程以 0 退出且无残留。

## 安装

- Apple Silicon：`Pi-Studio-0.0.6-arm64.dmg`
- Intel：`Pi-Studio-0.0.6-x64.dmg`
- 自动更新：对应架构的 `.zip`、`latest-mac.yml` 与 blockmap 文件。
- 系统要求：macOS 13+

本版本继续使用固定自签名身份，尚未经过 Apple Developer ID 签名与公证。首次打开时，请在“系统设置 → 隐私与安全性”中允许；也可以仅在确认安装包来自本项目 Release 后执行：

```bash
xattr -cr "/Applications/Pi Studio.app"
```
