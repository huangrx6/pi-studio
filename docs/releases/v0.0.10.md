# Pi Studio v0.0.10

这是 `v0.0.10` 的又一次同版本重建，集中修复会话可靠性、剪贴板、子智能体回传和界面细节。应用通过新的 `buildId` 识别本次重建，已有安装可以直接走应用内更新。

## 会话与稳定性

- 打开会话时一次性读完整个 transcript，滚到顶部就能看到第一条用户消息；此前按页懒加载，连续停在顶部不会再补页，长会话会停在某一页的边界上。
- 回合差异的 `at` 改成本轮最后一条助手消息的时间戳，历史轮次也能匹配到真实 diff；旧数据按「本轮最后一条消息 ≤ at < 下一条用户消息」的时间窗兜底，卡片不再退化成「已写入」并提示行数不完整。
- 超出视觉接口限制的图片在发送前自适应：单边超过 8000px 的长截图按原宽度切段（最多 6 段），明显超长才切，轻微超限只等比缩小；不受支持的格式能转码就转码，转不了改为一行说明，不再让整段会话持续返回 400。
- 子智能体会话结束时把最终回答写进自己的上下文文档，后台回传不再出现「completed without a text answer」；`bg_wait` 与 `subagent status` 直接返回这段正文，父智能体不必再轮询状态或翻子会话文件。
- 父智能体正在 `bg_wait` 时，reporter 不再额外插入 follow-up，避免已经总结完又被拉起一轮。
- Durable 存储的写锁等待从默认 5s 放宽到 15s，并发子智能体不再因 `database is locked` 直接失败；Studio 侧连接同步放宽到 15s，避免长提交把工作树写入顶掉。
- 修复「子智能体」面板永远为空：列表投影读取用量时调用了一个没导入的函数，每个含子智能体的会话在列表接口里直接抛 `ReferenceError`，而渲染层把错误静默吞掉。现已改为通过该模块已有的惰性访问器读取，并让刷新失败留下日志。

## 剪贴板与图片

- 适配 Electron 45 的剪贴板接口：`writeImage`、`readImage`、`availableFormats` 已被移除，服务改用 `ClipboardItem` 数组写入。右键「复制图片」恢复可用，缩略图、大图预览和输入框附件三个入口都走同一条路径。
- 图片一律以 PNG 交付，webp/svg 等来源也能粘贴到其它应用。
- 消息复制同时写入 `text/plain` 与 `text/html`：富文本编辑器会带上消息里的图片，纯文本输入框仍然收到正文。

## 界面一致性

- 图标收敛为六档尺寸（10/12/14/16/20/32）和两种图标按钮盒子（工具栏 28、密集操作 24），各面板自己的 24/29/32 覆盖与 105 处相邻像素差异全部并入令牌。
- 图片灯箱加入同一套系统：32px 按钮 + 16px 图标 + 1.75 描边，翻页箭头 40px + 20px 图标，计数器与按钮同高。
- 文本选区不再复用中性灰（两种主题下对页面底只有 1.14:1），改为混入当前强调色，浅色 1.48–1.52、深色 1.67–1.69，并在主题测试里守住下限。
- 流式「思考中」正文只在读者贴着底部时跟随最新内容，向上滚动立即停止跟随，滚回底部自动恢复；思考框不再把滚轮困在自己身上。
- 文件变更卡按 git 语义显示：新增文件标 `A` 并给出 `+N −0`，修改显示 `+N −M`，删除标 `D`；只有没有 diff 的整文件写入才退化为 `W` + `/ N 行`。此前新增文件会显示成没有数字的「已写入」——原因是回合 diff 已经落库（`added +161 −0`），但渲染层只在 `turn.diff` 事件到达时刷新；事件晚到或被错过，卡片就退回工具参数，而 `write` 工具本身不带 diff。现在快照接口带上已存的 diff，回合结束刷新时并入，卡片与 git 保持一致。
- 子智能体记录页的长指令默认折叠成三行并使用整列宽度，下方提供「展开完整指令 / 收起指令」；元信息行改为 13×16 内边距、16px 图标、12.5px 数值，不再挤成表格。
- 子智能体总览的所有行收敛到同一条内容轨道：聚合格与搜索行此前用了 `margin` 简写，把容器的 `margin-inline: auto` 覆盖掉了，1512px 窗口下标题在 326–1186、其余行在 32–892，整体左移 294px。现在四行共用边界，并由浏览器 QA 守住。
- 「编队」视图换成真正的图：React Flow 负责画布与连线、dagre 负责布局，主智能体垂直居中，子智能体按「需要处理 → 运行中 → 已结束」从上到下排列，连线随状态变色（运行中虚线、失败红、等待警告色）。原来的固定槽位 + 伪元素连线方案已删除。

## 本地路径与浏览器

- 回复里的本地路径变成可点击链接：`travel/一周旅游计划.md` 出现在正文、表格或行内代码里都能点，左键在右侧栏打开文件预览，右键给出「在 Finder 中显示 / 用某应用打开 / 复制路径」。检测保持保守——需要路径根或以已知扩展名结尾，`已交付（travel/` 这类正文不会被误判，代码块和已有链接原样保留。
- 地址栏的聚焦状态改由胶囊自己显示：全局 `input` 样式（36px 高、8px 圆角、方形焦点环）此前的优先级高于地址栏规则，聚焦时会画出一个溢出胶囊的方角框。现在输入框重置高度、圆角与阴影，焦点环跟随胶囊圆角；子智能体搜索框同类问题一并修正。
- 右侧栏新增内嵌浏览器标签：后退、前进、刷新、地址栏、用系统浏览器打开。页面运行在独立分区的沙箱 webview 里（无 preload、无 Node），非 http(s) 导航在 attach、导航与请求三层被拦截，摄像头/定位等设备权限默认拒绝。会话里的链接点击现在直接开在这个面板里，并复用同一个标签。

## 性能与快捷键

- 打开一条 2000 条消息的会话：由 20.4 秒降到 1.4 秒，DOM 从 5.6 万节点降到 2 万出头，长任务阻塞从 3.0 秒降到 1.0 秒。
- 会话页不再随包携带历史请求快照：那 16 份快照占 8.6 MB，现在只带摘要，点开「执行轨迹」时才按需拉取那一条正文。
- 转录改为窗口化挂载：默认只渲染最近 24 轮，接近顶部时继续向上补 24 轮，滚动位置保持不变；大纲跳转会先把目标轮次挂载出来再对齐。
- 派生数据（工具结果索引、轮次折叠、时间戳、请求放置）按消息身份缓存，流式输出不再每帧重走全部消息；打开会话也不再复制每条消息。
- 一分钟内切回同一会话会复用上次读到的内容（最多缓存 3 个会话），切回大会话 0.96 秒。
- 新增性能门禁 `tools/qa/qa-performance.mjs`：对页面体积、DOM 节点、打开耗时与阻塞时长设阈值，回退即失败。
- 快捷键可配置：⌘K 命令面板、⌘, 设置、⌘B 侧栏、⌘J 右侧面板、⌘N 新会话、⌘⇧B 浏览器、⌘\` 终端、⌘⇧[ / ⌘⇧] 上下会话、⌘. 停止生成；设置里可录制替换，冲突会提示，可一键恢复默认。
- 侧栏与右侧面板加了布局隔离，宽度动画不再带动整棵转录重新布局。

## 指标与预览

- 实时指标新增「缓存命中率」：缓存读 ÷（未命中 + 缓存读 + 缓存写），输入卡片改为显示未命中部分，最近结果每行附带该轮命中率；没有缓存遥测的来源显示「—」而不是 0%。
- 流式阶段的缓存读/写也会写入当前 run，此前只有落库后的历史数据才有缓存计数。
- 文件预览新增 PDF：交给 Chromium 内置阅读器渲染，单文件上限 32MB，与内联媒体分开限额。

## 技能

- 技能安装范围新增 Agent 共享目录 `~/.agents/skills`，可以和 Studio 用户目录、项目目录并列选择，不必为每个工具各装一份。

## 验证

- `pnpm test`：600/600 通过。
- TypeScript 检查、Vite 生产构建、扩展 Schema 与 `git diff --check` 通过。
- Playwright QA 覆盖图标与灯箱几何、选区对比度、流式思考滚动、技能源总览与单源切换、会话历史与长文粘贴，以及深浅色视觉检查。

## 安装与升级

- Apple Silicon：`Pi-Studio-0.0.10-arm64.dmg`
- Intel：`Pi-Studio-0.0.10-x64.dmg`
- 自动更新：对应架构的 `.zip`、`latest-mac.yml` 与 blockmap 文件。
- 系统要求：macOS 13+

本版本继续使用固定自签名身份，尚未经过 Apple Developer ID 签名与公证。首次打开时，请在“系统设置 → 隐私与安全性”中允许；也可以仅在确认安装包来自本项目 Release 后执行：

```bash
xattr -cr "/Applications/Pi Studio.app"
```
