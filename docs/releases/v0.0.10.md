# Pi Studio v0.0.10

这是 `v0.0.10` 的同版本重建，汇总会话工作台、菜单栏任务中心、终端运行服务和发布链路的近期改进。应用通过新的 `buildId` 识别本次重建。

## 会话与工作台

- 大纲不再把少量采样刻度按整段会话高度铺开，12 个刻度现在以稳定的 28px 节奏紧凑排列。
- 每个刻度的完整 44×28px 区域都可以点击，不再要求精确点中细线。
- 悬停预览改为真正的按钮，点击整张预览卡也能跳转到对应问题；键盘聚焦刻度时同样可以预览。
- 已加载目标使用原生平滑滚动；尚未加载的长会话目标会先按条目 ID 拉取历史，再定位到目标消息。
- 深浅色主题统一使用现有浮层表面、边框、焦点态和阴影变量；低高度窗口会把行距压缩到 22px。
- 右侧工作台移除常驻开始标签，空态直接显示文件、终端、运行服务和临时聊天入口。
- 多标签在窄边栏中自适应宽度并按真实溢出渐隐，当前标签完整显示，固定工具按钮不会被挤走。

## 菜单栏任务中心

- macOS 菜单栏弹窗按“需处理、运行中、最近结束”组织后台任务，空态与窗口高度随内容收缩。
- 权限确认会进入需处理分组；每条完成结果独立维护未读状态，不会因打开应用而全部清除。
- 运行任务支持按本轮运行标识单独停止，避免误停同一会话随后开始的新一轮任务。
- 任务完成改用系统通知，不再主动弹出窗口抢占焦点；退出应用时提示运行中任务的中断后果。

## 终端、服务与更新

- 右侧工作台提供交互式 PTY 终端，以及按任务和全部范围组织的 TCP 监听端口视图。
- 服务归属根据 Studio 子进程关系和已登记工作区计算；终止进程前保留明确确认和边界校验。
- 应用内更新同时比较语义版本与构建指纹，因此同一版本重新构建也能被识别。
- 同版本重构建使用完整 ZIP 下载，避免新签名包与旧 blockmap 错配。

## 验证

- `pnpm test`：538/538 通过。
- TypeScript 检查、Vite 生产构建、扩展 Schema 与 `git diff --check` 通过。
- Playwright QA 覆盖 44×28px 点击区、28px 刻度间距、预览卡点击、平滑滚动采样，以及深浅色视觉检查。

## 安装与升级

- Apple Silicon：`Pi-Studio-0.0.10-arm64.dmg`
- Intel：`Pi-Studio-0.0.10-x64.dmg`
- 自动更新：对应架构的 `.zip`、`latest-mac.yml` 与 blockmap 文件。
- 系统要求：macOS 13+

本版本继续使用固定自签名身份，尚未经过 Apple Developer ID 签名与公证。首次打开时，请在“系统设置 → 隐私与安全性”中允许；也可以仅在确认安装包来自本项目 Release 后执行：

```bash
xattr -cr "/Applications/Pi Studio.app"
```
