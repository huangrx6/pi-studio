# Pi Studio v0.0.2

本次版本重点加入子 Agent 协作能力、Agent 工具权限管理，并修复斜杠命令的作用范围。

## 新增

- 集成 `pi-subagents`，可在全局或项目设置中配置默认模型、思考强度和思考上限。
- 支持按角色覆盖每个子 Agent 的模型与 thinking 配置。
- 新增子 Agent 总览和实时运行状态，统一展示前台、后台和并行子 Agent。
- 点击子 Agent 卡片可查看只读上下文，也可返回主 Agent 或进入总览；返回时会保留主对话的滚动位置。
- 新增 Agent 工具白名单，可按来源查看核心、扩展包和本地扩展提供的工具与命令。
- 扩展暂时卸载时保留已选工具及其来源信息；重新安装后可恢复对应配置。

## 修复

- `/thinking` 不再错误打开设置页，只调整当前 Pi 会话的思考强度。
- 支持 `/thinking high`、`/thinking x-high`、`/thinking default` 等直接设置形式。
- `/model` 改为输入框模型选择器，不再跳转设置页。
- 没有活动会话时，不会修改全局默认 thinking。
- 扩展、Prompt 和 Skill 命令保留原生命令与参数，直接交给 Pi 执行。

## 优化

- Studio 原生命令使用独立路由表，扩展命令无需逐个适配界面。
- 子 Agent 会话路径严格限制在父会话派生目录内，并拒绝路径穿越与符号链接。
- 推理记录、工具调用和子 Agent 结果继续使用统一会话视图。
- 完善工具与子 Agent 设置页样式，统一尺寸、边框、间距、状态色和窄窗口布局。

## 验证

- `pnpm test`：89/89 通过。
- `/thinking` 浏览器交互验证通过，仅修改当前会话，不触发全局设置变更。
