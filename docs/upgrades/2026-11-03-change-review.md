# 当前变更梳理与加固（2026-11-03）

本轮基于工作区已有改动做审查与修复，保留原有功能方向，没有重置或提交用户改动。

## 变更地图

| 功能域 | 当前变更的主要内容 | 主要边界 |
| --- | --- | --- |
| Durable 1.5 | 会话视图投影、实时事件、任务图、工具 JSON Schema、升级检查 | Durable 保持执行事实来源；Studio 适配其视图 |
| 子智能体 | 后台任务、监督回复、并发限制、预算、Git 工作树隔离 | Durable 管任务；Studio 管配置与工作树元数据 |
| 模型对比 | 从同一会话建立两个分支，分别运行、查看用量、应用或丢弃 | 公共会话 UUID、内部 Durable ID、工作树 ID 必须区分 |
| Skill Hub | 目录/registry 来源、预览、安装、更新、完整性校验 | 来源目录、隔离暂存区、明确安装目标 |
| 凭据与 MCP | 加密凭据库、工具占位符、敏感输入提醒、OAuth、连接测试 | safeStorage、执行边界、持久化与渲染边界 |
| 会话界面 | 动作面板、大纲与分页、上下文占用、用量筛选、子智能体视图 | Renderer 只消费可序列化投影 |

总体方向可以保留。最需要修复的是跨边界的身份、生命周期与数据语义；直接按文件长度拆分全部代码，无法解决这些问题。

## 已修复的问题

| 问题 | 修复结果 | 主要验证 |
| --- | --- | --- |
| 在 `beforeTool` 展开凭据，Durable 会将明文写入工具执行 checkpoint；结束后脱敏拦不住流式输出 | 新增执行边界包装，checkpoint 保留占位符；在工具执行时展开，对输出、details、diagnostics、嵌套调用和异常做脱敏，处理跨 chunk 的完整值 | 真实 Harness + MemoryStorage，检查全部持久化写入及实时视图 |
| 短凭据、对象键、相互重叠的值可能漏脱敏或重复替换 | 统一脱敏器；保护已有占位符；保留用户输入值的原始空白并按 UTF-8 字节检查大小 | 精确值、短值、键与分段输出回归 |
| 预算查询缺少数据库导入，且把公共 UUID 当数字转换 | 从 Studio 会话记录解析内部 ID，并使用会话实际所属工作区的设置 | 调用预算服务，覆盖公共 UUID、实际作用域和重复 child 引用 |
| 累计用量实际只统计最近 8 次请求，旧请求被裁剪后可能再次计入 | v17 增加最小数值记账投影，UI 历史继续保留 8 条，记账按 request ID 去重 | 20 次请求、旧请求重放、重启、迁移与删除清理 |
| 项目显式配置恰好等于用户配置时，会被当作继承删除 | 仅对旧格式执行一次 v2 迁移，之后保留项目覆盖的明确语义 | 用户默认值经过相同值再变化的回归 |
| 模型对比快照漏传工作树 ID，真实 UUID 的指标始终为零 | 统一返回分支身份；指标查询在主进程解析公共 ID | 快照身份、公共 ID 指标与采用分支回归 |
| 新问题尚未回答时，比较面板可能展示父会话的旧答案 | 查找答案遇到当前用户消息即停止 | 继承旧答案、新问题尚未回答的场景 |
| 清理失败被 `allSettled` 吞掉，停止失败后仍可能删除分支 | 每条分支按停止、等待清理会话、清理残留工作树的顺序处理；汇总并返回失败 | 停止失败后不删除、部分提交失败回收 |
| 工作树并发创建可绕过容量限制，稳定 ID 并发创建可能冲突 | 托管工作树异步变更按管理根目录串行化 | 并发同 ID 与容量限制的真实 Git 测试 |
| 清理失败时删除了元数据，应用成功但清理失败却标成 removed | 保留失败记录以便重试；已应用的树明确标记 applied | 生命周期、冲突保留、公共 UUID 归属清理 |
| 工作树文件名按换行/制表符解析，中文或特殊名称显示错误 | Git 使用 NUL 分隔输出；检查详情复用同一份 diff，按主键读取单条记录 | 中文、制表符、换行文件名的真实 Git 测试 |
| 子智能体等待监督回复或还有队列任务时，空工作树可能被提前回收 | 保留该工作目录，等后续工作结束再完成生命周期；删除会话统一经过等待任务结束的清理入口 | 监督等待与多 reporter 生命周期回归 |
| Skill Hub 的缓存只新增不清空，已删除/停用来源仍可能可安装 | 按来源保存完整缓存，刷新替换；修改/停用/删除使缓存失效，迟到的请求不能写回旧缓存 | 条目删除、停用、预览安装回归 |
| 刷新结果与缓存结果有两套 DTO，更新提示不一致，逐条重复查库 | 一个目录投影函数，每次读取一次安装记录；同名但不同来源不标记为可更新 | 原有安装与升级流程回归 |
| 安装确认可以切换预览之外的工作区；本地包可先完整复制再发现过大 | 预览绑定目标工作区和来源；复制前检查文件图与大小，复制后检查指纹 | 工作区不一致时拒绝且不产生目标目录 |
| 远端下载先完整读入内存再判断大小；loopback URL 被误当文件 | 读取过程中限制字节数；统一 HTTP(S) 来源判断，重定向后的 URL 用于解析相对下载地址 | 无 Content-Length 的超限流、loopback 与重定向 |
| OAuth 回调错误文本直接插入 HTML；浏览器打开失败可能留下未处理 Promise 拒绝 | 转义错误文本；提前验证环境引用，并立即观察回调等待的拒绝 | 现有 OAuth 状态与请求头测试、全量门禁 |
| 对比面板迟到轮询可能恢复已丢弃分支；采用和丢弃可交叉触发 | 保留本地已确认删除状态，互斥操作；只允许采用已完成分支 | 迟到快照与另一个分支继续更新的回归 |

## 收敛后的职责

- `electron/core/subagent-config.cjs`：子智能体默认值、范围与校验的唯一实现；设置写入严格校验，运行时读取旧数据时允许回退。
- `electron/services/subagent-usage.cjs`：UI 预算和运行时准入共用同一累计逻辑。
- `electron/core/secret-vault.cjs`：纯占位符与脱敏逻辑。
- `electron/services/secret-tool-runtime.cjs`：工具真正执行时的凭据处理，注册新工具和热更新走同一个入口。
- `electron/services/managed-worktrees.cjs`：Git 操作、串行化、检查与回收；会话层负责确认任务已停止。
- `electron/services/skill-sources.cjs`：来源适配、缓存与安装编排；目录快照只保留一种渲染投影。
- `web/src/lib/comparison-state.ts`：可独立测试的对比快照合并语义。

## 验证与边界

审查开始时已有 490 项测试全部通过。本轮增加 16 项回归测试，合计 506 项；新增测试针对原有测试遗漏的跨模块路径，而非复制实现。

最终门禁包括 `extension:schema`、`pnpm test`、`pnpm run build`、`git diff --check` 和示例扩展验证。浏览器交互检查使用仓库已有 `tools/qa/qa-ui.mjs`，API 为本地 fixture，不访问实际账户或真实模型服务。QA 输出仅写入被忽略的 `.qa/`。

数据库 v17 从现有请求历史初始化记账投影。旧版本已经裁剪的会话请求不能凭空恢复，因此旧会话历史累计值只能继承仍保留的记录；迁移后的新请求不再受 UI 历史条数限制。记账只保留 ID 和数值，随会话删除，不保存提示词或凭据。

工具仍是显式信任的 Node 代码。凭据包装处理正常工具契约中的精确值传递与回显，不是操作系统沙箱，也不能约束受信任扩展自行访问系统、写日志或变换后外传凭据。

设置页、Skill Hub、凭据库、模型对比和共享列表/详情组件完成了统一视觉与交互收敛；浏览器 QA 覆盖深浅色、窄窗口、键盘焦点、空态、错误态与剪贴板流程。没有验证真实 OAuth 服务或真实提供方计费。构建仍有已有的大 chunk 提示；按功能拆分 App 的加载边界可以单独进行，不应与本次生命周期修复混在一起。
