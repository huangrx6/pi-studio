# 视频分镜工作台 · 任务与实现清单

一部作品有两个视图。**创作流程**把想法、讨论、素材缺口和已采纳的决定留在一张图上。**制作工作台**负责逐镜编辑、预览和导出。「网页来源」是可选示例。下面的复选框跟踪正式应用的开发。HTML 原型使用真实 React Flow 画布，本地规则演示 Agent 对话和移交，MP4 导出演示操作流程。

## 创作流程如何工作

| 节点 | 用户能做什么 | 怎样决定下一步 |
| --- | --- | --- |
| 创作起点 | 写想法、批量放素材，或请 AI 一起找方向。题材、片名和画幅均可后定。 | 目标已经清楚时直接给方向。输入很少时，只针对最影响剪辑的一件事追问，例如观众或情绪。 |
| 讨论方向 | 看两种具体讲法，采用其一、提出自己的讲法，或继续头脑风暴。可以点回旧节点，从那里另开一条讨论。 | 记录用户选择、补充说明和上一节点。用户想再聊就继续长出节点；采用方向后才核对它实际需要的素材。 |
| 安排素材 | 直接拖入缺少的画面或原声，指出已有哪份素材可用，也可以把缺口记为待补。 | 知识讲解可以先用文字分镜卡；想用誓词原声时才询问相应录音或视频。已有信息充分时跳过此节点。 |
| 确认制作方案 | 在一处核对叙事方向、镜头节奏、素材、画幅和待补项。可以继续聊。 | 在 AI 流程中，点「确认方案并生成分镜」后进入工作台并生成整片候选。允许带着明确的待补项开工。 |
| 制作中回看 | 在两个视图间切换，查看为什么这样剪，从旧决定分支讨论；时间线上的镜头继续可编辑。 | 新版方案由用户确认后同步。已手改的镜头保留，涉及重做的镜头按差异单独应用。 |

例如，婚礼项目只有一张合照时，选「从一张合影开始」可以直接形成方案。选「让誓词串起一天」会多出一个与誓词有关的素材节点。知识讲解已有讲稿和示意图时，可以略过补素材，直接讨论「先解释原理」还是「先做实验」。

## 产品任务清单

- [x] **新建作品**　从一个起点节点填写创意或放素材，也可以从头脑风暴开始。片名、题材和画幅可调整。
  - 验收时，输入一句讲解主题、只放一张照片或请求灵感都能继续。切换题材时保留已填内容和已选文件。
- [x] **渐进式讨论与确认**　每个回复推进一个有依据的节点。已回答的信息可回看，分歧可保留为分支。AI 结合当前分支和已有素材生成问题和建议，用户也可以选择基础流程。
  - 验收时，同一批素材选择不同叙事方向，可得到不同追问。选择「再讨论」后保留此前的方向。用户确认前一直处于筹备阶段。
- [ ] **整理素材**　批量导入图片、视频、音频、文稿，显示类型、顺序、预览和可选用途。创作中途也能补素材。
  - 验收时，同一张照片可用于不同镜头；只有音频的镜头会标出待补画面；文件无法读取时能定位并替换。
- [ ] **选择叙事结构**　自由创作按提纲或素材顺序起稿；知识讲解可按问题、原理、例子、结论组织；婚礼纪实可按现场、仪式、祝福组织；产品演示可按场景、操作、结果组织。
  - 验收时，有对比需求时才给素材标注「修改前」「修改后」。用户可以跳过仪式、例子或任何建议段落。
- [x] **生成并审核分镜**　工作台使用所选文本模型读取已确认分支、素材和制作 Skill，生成可逐镜预览、采用或放弃的草稿。镜头能引用方案已有的图片、视频和音轨，也可生成带字幕的文字镜头。
  - 验收时，讲解的事实或引文可回到输入文稿。婚礼的原话可回到录音或用户提供的誓词。未提供的现场内容显示为拍摄建议。
- [ ] **编辑单镜并预览**　左侧选镜，中间编辑，右侧预览。支持调顺序、时长、取景、主体动作、字幕、原声、旁白、音乐和音效。自然语言修改先给出可撤销的候选。
  - 验收时，把一镜字幕上移、压低音乐，其他镜头的设置与素材引用保持一致。改时长后播放头、字幕和声音一起更新。
- [ ] **保存与交付**　关闭后可恢复作品。编码前查看缺失素材、分辨率、时长、字幕与声轨，支持进度、取消和重试。
  - 验收时，在系统播放器打开导出的横屏或竖屏 MP4，核对点击或誓词的声画同步。取消后可继续编辑并重新导出。

## 三组贯穿开发的验收素材

| 作品 | 起步材料 | 第一条成片的验收点 |
| --- | --- | --- |
| 知识讲解「冬天为什么容易有静电」 | 一份三段提纲；示意图可以后补 | 第一次生成已有可编辑结构和待补画面。补入示意图后能只重做「电荷转移」一镜，横竖屏字幕均可读。 |
| 婚礼纪实 | 一张合影也能开工；完整用例再加入仪式视频和一段誓词录音 | 能指定合影做开场、保留现场原声，让配乐在誓词处降低。片段缺失时可补录、重排或删镜。 |
| 产品演示「网页来源」 | 同一回答的旧版截图、新版截图，可选实际打开后的弹框画面 | 指针落在地球入口，字幕避开按钮，结果镜可读。仅有新版录屏时仍能做单版本演示。 |

## 实现清单与顺序

- [x] **1　作品、流程与分镜契约**　定义版本化的作品、素材、讨论节点、镜头和音轨。节点记录父节点、提问、回答、素材引用与所采纳方案。作品保存当前分支及已确认方案版本。镜头有稳定 ID、来源方案 ID，以及取景、人物／物件／环境、动效、字幕和声音设计。
  - 验收时，用三组材料恢复同一作品的讨论与分镜。比较过的方案可回看，相同素材能复用。
  - 已接入右侧工作台的「视频分镜」。创作起点和作品素材随工作区保存。窄栏上下排列，宽栏并排，使用工作台的全屏按钮。三类作品的分支、已确认方案、镜头和素材复用已用 SQLite 重开验证。
- [x] **2a　流程画布与下一步决策**　先填写想法或添加素材。出现后续节点后，宽屏可并排查看流程图和当前问题，窄栏可按需打开流程图、选中节点后继续回答。默认由所选文本模型结合当前分支的回复和素材决定下一步，基础流程沿用内置规则。
  - 依赖 1。只有起点时不预画后续节点。回答不同，图上实际生成的节点不同。重复提交、请求重试或切换分支均不会重复创建节点。
  - 已用桌面应用验证从同一节点分别尝试两种讲法、把缺少的片段记为待补、确认两版方案并在重开后继续原分支。接入 Agent 后的节点校验属于第 5 步。
- [x] **2b　工作台移交与素材管理**　「开始制作」把已确认的叙事节拍逐一建成镜头。每个方案版本保有独立草稿，作品内共享素材。镜头意图、时长、构图、主体、场景、运镜、声音说明与素材选择自动保存。
  - 初稿使用每镜 4 秒的占位时长，自定义讲法以一镜起稿。素材缺口落到相应镜头，补选匹配文件后可核对。建立新版前能查看原镜头和新版意图，并逐镜沿用旧版编辑。
  - 主进程按作品和素材标识读取本机源文件。音视频支持按字节范围预览，尺寸和时长来自实际解码。图片支持原图或系统缩略图，纯文本文稿支持节选。找不到源文件时，可重新定位同类型文件，沿用所有镜头引用。字幕合成、转场和混音预览属于第 3 步。
  - 桌面已验证两版之间独立编辑、重新打开后恢复选中镜头，以及导入、播放、移动和重新定位真实视频。幂等开工和失败时回滚另有存储测试。
- [x] **3　先打通手工成片**　右侧「视频分镜」可以直接打开「网页来源示例」。四镜依次是桌面开场、旧版来源条、点击新入口和展开网站列表。全片 15 秒，逐镜可改字幕、时长、素材、镜头运动、入镜转场和音量。示例自带四段中文旁白，第 8.95 秒的点击声与地球按钮的指针同步。
  - 选中镜头即可查看用实际素材绘制的分镜静帧，核对字幕与点击位置。宽屏并排显示编辑区和预览，窄栏横向选镜。点击「生成整片预览」即可播放，点时间线上的镜号跳到对应切点。编辑后可更新预览，直接导出也会先处理最新编辑。保存使用播放器对应的同一份 MP4。
  - 逐帧合成支持图片、短视频和无图文字镜头。按已确认方案输出横屏 1280 × 720、竖屏 720 × 1280 或方形 960 × 960，30 fps。编码使用 Electron 的 H.264、有声时使用 AAC，设备缺少编码器时会显示具体原因。预览可以取消、重试，关闭工作台会释放临时文件。
- [x] **逐镜配音与生图**　在「设置 → 模型配置」编辑来源，按语音合成、图像生成分别登记服务支持的模型 ID。已配置的来源连接和凭据可复用。媒体生成对接兼容 OpenAI 的语音和图像接口。
  - 在「镜头素材」里选择「模型配音」或「模型生图」。模型及音色随作品保存，生成的每个候选归属于发起请求的镜头。可以先试听、看图、比较版本，采用后才更新成片。采用旁白时保留原来的入点，时长不足会延长该镜。示例的四段预录旁白也可逐镜更换。
- [x] **4　制作 Skill**　随应用提供「分镜导演」，按产品演示、知识讲解、婚礼或自由创作的实际素材编排。每次生成都会读取这份 Skill 的正文。如果当前工作区可用的技能里有 `remotion-markup` 或匹配画幅的 Speclip 字幕技能，生成时也会带上这些指导。建议预览列出实际使用的技能和模型。[内置分镜导演](../../assets/storyboard/skills/storyboard-director/SKILL.md)
- [x] **5a　整片草稿与单镜修改**　「AI 生成整套分镜」根据当前确认方案生成候选序列。「AI 改这一镜」展示所选镜头的原值、建议值和合成静帧。沿用的镜头保留身份与音轨，删除镜头及关联音轨前提示数量。建议提交后作品仍可编辑，采用时核对相关镜头、素材和音轨是否已变化。
  - 整套或单镜均可选用 Studio 已启用的文本模型。图片理解模型最多接收 6 张关联素材缩略图，纯文本模型使用素材名称、文稿节选和已记录的镜头说明。视频和录音提供素材信息与既有时序。
  - 模型写出剪辑参数，本地按帧计算指针、强调框、运镜、转场、字幕和声音。强调框可指定画布位置、范围、短标签与入退场时间。网页来源的全片生成、单镜修改、预览与有声 MP4 已有桌面验收。[桌面用例](../../tools/qa/qa-storyboard-director.mjs)
- [x] **5b　AI 创作讨论**　每次回复由所选文本模型读取本分支的讨论、可用素材和策划 Skill。下一步可以是追问、提出不同讲法、索取某份素材或交回待确认的方案。用户可以修改方案、补文件、使用现有素材或把缺口记为待补。[创作策划 Skill](../../assets/storyboard/skills/storyboard-planner/SKILL.md)
  - 用户确认后进入制作工作台，由同一模型按已确认分支生成整套分镜，预览后可采用或放弃。模型请求失败可重试；已保存的讨论可重新打开。[桌面用例](../../tools/qa/qa-storyboard-planning.mjs)
- [ ] **6　混合素材与导出可靠性**　接入视频入出点、原声与独立音轨、语音期间配乐压低、字幕安全区、烧录字幕或单独 SRT。主进程管理 FFmpeg 编码任务、取消、临时文件清理及成品登记。
  - 依赖 3、5。三类作品走完整流程；在 macOS 和 Windows 核对 H.264、AAC、时长与音画同步。测试缺素材、无音轨、空间不足和中途取消。

### 代码落点

- 界面与交互放在 `web/src/features/video-storyboard/`，工作台入口接入 `web/src/shell/right-panel/`。创作草稿、镜头选择、播放位置分别维护，拖动播放头不会改错当前编辑的镜头。
- 流程图布局与节点编辑分别维护。项目现有子智能体视图已使用 `@xyflow/react`，新功能可以沿用画布交互方式，节点内容和创作状态由视频功能维护。[仓内现有画布](../../web/src/features/subagents/SubagentFlow.tsx) · [React Flow 自定义节点](https://reactflow.dev/learn/customization/custom-nodes)
- 分镜工作台的单次生成由 `electron/services/video-storyboard/` 调用 Studio 模型服务。制作 Skill、素材读取、候选校验和采用各自独立。SQLite 保存作品、素材索引和采用的分镜；待审建议在当前应用进程内保留。
- 主进程负责素材路径、分段读取、临时成片和保存对话框。工作台的 `film/` 负责按帧时间线绘图、混音，再通过 Mediabunny 和 WebCodecs 编码。视频和声音按段读取，渲染过程通过作品与素材 ID 访问文件。已有会话附件的生命周期、外置盘和长期导出任务继续在交付阶段处理。
- 测试按执行边界放在 `tests/web/`、`tests/electron/`、`tests/integration/`。桌面交互用例在 `tools/qa/` 复用上述三组素材，验证新建、单镜修改、重开和可播放的成片。

### 模板与 Skill 来源

产品演示、知识讲解和婚礼纪实的叙事模板由 Pi Studio 维护。模板描述「这一类视频通常怎样讲」，制作 Skill 指导具体工序。按画幅选横屏或竖屏字幕，有口播素材才启用口播剪辑，交付时采用 FFmpeg 规范。通过现有 Skill Hub 记录启用来源和版本；需要转录、媒体工具或外部服务时，在对应制作步骤检查可用性。[Pi Studio Skill Hub](../skill-hub.md) · [Speclip Skills](https://github.com/linyqh/speclip-skills)

| 工序 | 候选制作 Skill | 需要的输入与可验收产物 |
| --- | --- | --- |
| 横屏或竖屏字幕 | 按画幅选 `landscape-subtitle-layout` 或 `portrait-subtitle-layout` | 逐句时间码与主体位置 → 断句、字号与安全区；用人脸、讲解图和操作按钮校验遮挡。[横屏](https://github.com/linyqh/speclip-skills/blob/main/landscape-subtitle-layout/SKILL.md) · [竖屏](https://github.com/linyqh/speclip-skills/blob/main/portrait-subtitle-layout/SKILL.md) |
| 讲解口播剪辑 | `talking-head-editor` | 可用的带时码转录与源片段 → 可回溯到原片的保留段落和剪辑点。[口播剪辑](https://github.com/linyqh/speclip-skills/blob/main/talking-head-editor/SKILL.md) |
| 编码交付 | `ffmpeg-best-practice` | 媒体信息与导出目标 → 编码参数与核验步骤。实际编码由 Studio 的导出服务执行。[FFmpeg 制作规范](https://github.com/linyqh/speclip-skills/blob/main/ffmpeg-best-practice/SKILL.md) |
