# 会话内容区

Git 项目按「项目 → 工作树 → 会话」显示。每个工作树行显示实际检出的分支或游离提交，旁边的主题色圆点代表主工作树，叠放的文件夹代表链接工作树。悬停或用键盘聚焦这一行可查看名称及路径。在同一目录切换分支后，会话历史仍在原来的行下，中间区域恢复目标分支的标签。普通目录直接列出会话。团队群聊归入创建它的工作区，独立的临时对话从临时对话列表进入。

底部状态栏有两个入口。点分支名称在当前目录切换或创建分支，点旁边的工作树图标可搜索并打开另一个检出目录。其他工作树已检出的本地分支会标明占用位置。Git 已标记为失效的登记会在工作树菜单中显示，并禁用打开操作。

从「设置 → Git」、工作树菜单或左侧项目行都可以创建工作树。「新建分支」会从指定起点创建分支，「已有分支」可选尚未被其他工作树检出的本地分支。工作树名称也是新文件夹的名称，默认根据分支生成，可以自行修改。此后在该目录切换分支时，目录名会保留。勾选「创建后切换到此工作树」会在创建成功后进入新目录。

中间标签按工作树目录和当前分支分组。同一分支可以同时打开多个会话、文件和差异。点击左侧会话会打开或选中它的标签，关闭会话标签后，仍可从左侧重新打开。单击右侧文件树可预览文件，双击可保留标签。回合变更始终关联产生它的会话。右侧可在文件、Git 之间切换。

会话检视独立浮在当前对话区右上角。任务创建或子智能体启动时显示一行摘要，点击可展开进展、轨迹和子智能体。展开后可拖动四边或四角调整大小，点「放大会话详情」铺满当前对话的消息区。点还原或按 Esc 可回到原来的位置和尺寸。每个会话单独保存浮卡的位置、尺寸和显示状态。

点击主窗口右下角的按钮可展开悬浮工具面板，其中提供终端、浏览器和插件标签。面板可在编辑区和右侧面板上方移动，放大后覆盖整个内容区。收起面板后可以继续对话，再次打开会恢复当前会话的工具标签。

Studio 在 SQLite 的 `session_layouts` 中保存每个工作树分支的标签顺序、选中项和文件树状态。普通目录按工作区路径分组，每个会话标签单独保存阅读位置。工具面板单独按会话保存。重启时恢复上次的工作树、会话和活动标签。文件内容从原文件读取，运行记录由 Pi Durable 提供。

主会话、临时对话和子智能体详情共用一套消息视图。内容按发生顺序排列，下面的展示规则也适用于从数据库重新打开的旧会话。

| 读者要看什么 | 默认展示 | 展开或操作 |
| --- | --- | --- |
| 自己发过什么 | 用户正文、文件和技能引用、图片、附件 | 打开文件、预览图片、复制或编辑消息 |
| Pi 正在做什么 | 当前回复下的一行文字显示动作和目标；并行调用、等待与重试会在原位更新 | 点当前动作可在聊天中展开执行记录 |
| Pi 说了什么 | 中间说明与最终回答分别保留在原位置 | Markdown 链接、代码、图片与宽表格可独立操作，复制回答使用最终正文 |
| 本轮做过什么 | 使用工具的回复在结束后显示一个「查看执行记录」入口 | 按时间翻阅各步，展开具体调用；有失败时可以直接展开失败步骤 |
| 一次工具调用发生了什么 | 一行显示动作、目标和运行状态，收起整段时仍能看到失败步数 | 展开后可查看完整命令、参数和结果，失败步骤先展示错误原因 |
| 子智能体在做什么 | 创建、等待、查询等操作显示动作和智能体名称 | 会话进展面板列出每个子智能体的最终或当前状态，从对应行进入详情 |
| 有哪些可用结果 | 图片按产生的位置展示，网页来源按回合去重，已修改文件保留自己的清单 | 预览图片、打开网址、比较或撤销文件变更 |
| 为什么整个回答中断 | 重试时进展行显示重试次数，中断和回合错误显示在正文之后 | 排查模型请求时，可以在「会话检视」中选择「轨迹」查看该次调用的上下文 |

## 每一步显示什么

| 步骤 | 收起时 | 展开后 |
| --- | --- | --- |
| 思考 | 显示「思考」 | 显示模型提供的正文；模型隐藏正文时显示占位说明 |
| 命令 | 动作和一行命令，长命令用省略号收尾 | 完整命令、其他参数、输出或错误 |
| 浏览、读取和查找文件 | 文件名、目录或查询词 | 调用的实际参数和结果。可定位的文件支持直接打开 |
| 写入和编辑文件 | 动作和文件名 | 具体操作的参数和结果。回合结束后可从文件变更清单查看差异 |
| 搜索和读取网页 | 查询词或目标站点 | 可查工具返回内容。回答底部的地球按钮打开来源弹框，按站点列出本轮成功获取的网页 |
| 子智能体 | 启动、等待、查询、继续或停止，以及操作对象 | 该次调用的参数与返回值。进展面板提供子智能体自己的完整会话 |
| 图片和其他工具 | 生成的图片直接显示在回复中；过程截图在所属调用旁标注数量 | 展开该调用可预览过程截图、查看参数和结果 |

默认设置下，助手在多步任务中通过普通回复文字说明已经确认的发现或方案变化。进展行根据真实的调用和返回更新。展开长记录时先显示最近一页，可以向前翻阅。

## 工作台文件刷新

工具通过 Durable 写入文件并成功落盘后，主进程通知工作台对应文件已变化。Shell 命令涉及的文件通过已有的回合 Git 变更通知刷新，撤销回合变更也会发出通知。通知使用应用进程内生成的文件标识。工作台只重读正在展示且标识匹配的文件，其他已打开的文件在下次查看时重新读取。正在编辑的草稿保持在编辑器里，保存前会核对磁盘上的原始内容。

## 永久删除会话

Studio 先停止会话及其子智能体的任务，在同一 SQLite 事务中删除 Durable 消息、提交、任务及文档，以及 Studio 的会话记录、回合差异、请求轨迹、会话指标和权限设置。托管工作树随会话清理。数据库同时登记待清理的文件，删除会话附件和已接入清理的插件画布。中断或遇到磁盘错误时，下次启动从尚未完成的条目继续清理。

输入草稿和排队消息保存在窗口的 IndexedDB 中。界面确认会话删除后会立即更新该快照。启动时，Studio 根据成功加载的会话列表清掉失去归属的草稿和队列。

分叉会话引用原会话分叉点前的消息。原会话可以与引用它的分叉一起永久删除。单独删除原会话时，需要先删除引用它的分叉。

项目文件、用户导出的文件、独立下载、全局用量统计和 SQLite 迁移备份各有自己的保存周期。永久删除会话会删除活库中的对应记录。迁移备份依旧可以用于恢复升级前的数据。

## 维护入口

- `ChatMessage.tsx` 负责用户消息，`MessageActions.tsx` 负责消息操作。
- `turn-content.ts` 按用户提问划分回合，按调用 ID 配对并行返回的结果，再把消息块整理成正文、图片和执行段。流式与历史消息使用相同规则。
- `AssistantTurn.tsx` 编排回合状态、各段正文、执行段、来源、错误与文件结果。
- `narrative-stream-model.ts` 将回合事件整理为步骤，`NarrativeWorkstream.tsx` 显示执行进展，`ActivityDetails.tsx` 按需展示单步详情。
- `WebSources.tsx` 展示来源，`web-sources.ts` 从成功的网页工具结果中识别站点。文件变更、图片预览和 Markdown 由各自已有的组件负责。
