# Terminal symbols

`SymbolsNerdFontMono-Regular.ttf` is the unmodified Symbols Nerd Font Mono from
[Nerd Fonts v3.4.0](https://github.com/ryanoasis/nerd-fonts/tree/v3.4.0/patched-fonts/NerdFontsSymbolsOnly).
The adjacent MIT license is supplied by upstream.

The font is packaged with the terminal for offline icon support. Its CSS range
limits it to symbols, preserving the user's normal monospace face for text.
