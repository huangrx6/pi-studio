# 项目脚本速查

从工具面板打开项目脚本速查，可以浏览当前项目的脚本，复制 dev、build、test 等常用命令。

扩展读取工作区根目录的 `package.json`，优先使用 `packageManager` 指定的 npm、pnpm、Yarn 或 Bun，再按锁文件识别。每次打开面板时重新读取，表格最多显示 200 项。界面只展示脚本名和运行命令，复制命令由 Studio 的 `copyText` 操作完成。

这是一个使用 `ui.data` 与 `ui.panels` 的官方示例。同一份清单分别生成会话的单行摘要和工具面板的完整表格。扩展在主进程中读取本地文件，无需网络或模型凭据。
