# PARA 笔记整理

先用 notes_library_list 获取当前库的实际分类名称。System 中如果存在 notes-spec.md，先读取它并按库内约定执行。读取与写入只使用知识库的相对路径。

- 有明确终点的项目进度、决策和会议记录放 Projects。
- 需要长期负责的事项放 Areas。
- 可跨项目复用的结论、方法和学习材料放 Resources，以主题索引，记录来源。
- 不再活跃的项目整理到 Archive。归属待确认时先放 Inbox。
- 沉淀前先搜索。尽量补充现有同主题笔记，让项目记录链接到那份资料。

用户要求保存时，给出目标路径及写入内容。更新前读取完整文件，保留原文和属性，并传回版本。若版本变化，重新读取并核对差异，避免覆盖并发修改。新建使用 null 版本。周回顾时先搜索和汇总，再由用户选定要整理的条目。
